## Slide 3: Hvordan fungerer det?

### 📱 Moderne QR-kode Basert System

**For deltakere:**
1. Skann QR-koden på deltakerkortet
2. Se all din informasjon
3. Bekreft at informasjonen stemmer
4. Velg soverom
5. Se kurs og program
6. Delta i aktiviteter

**Ingen app å laste ned - fungerer i nettleseren!**

### 🖥️ Fleksibel Teknologi

**Felles PC-stasjon:**
- Touchskjerm for enkel betjening
- Strekkodeskanner for rask QR-scanning
- Webkamera for selfies og verifisering
- Perfekt som kiosk ved inngang

**Deltakernes mobiler:**
- Åpne nettsiden på egen telefon
- Skann QR med mobilkamera
- Fungerer på både iPhone og Android

**Begge samtidig!** ✨

## Slide 5: For Arrangører - Mindre Arbeid

### 📋 Før Arrangementet (5-10 minutter)

- 📥 Importer deltakerliste fra CSV
- 🏷️ Print QR-koder på 5 minutter
- 🎮 Aktiver/deaktiver aktiviteter med ett klikk
- 📅 Legg inn program en gang – alle ser det
- 🛏️ Sett opp soverom

- ✅ **Bekreftelsesoversikt** - Hvem har sjekket inn?

- 🖨️ **Automatisk brannliste** - Print oppdatert liste når som helst
- 💬 **Motta tilbakemeldinger** - Direkte fra deltakerne

- Gjenbruk oppsettet til neste arrangement

## Slide 10: Teknisk Men Brukervennlig

### 💻 Teknisk Stack (for de som lurer)

**Backend:**
- Node.js + Express
- SQLite database (fil-basert)
- Ingen ekstern server nødvendig

**Frontend:**
- Ren HTML/CSS/JavaScript
- Fungerer i alle moderne nettlesere
- Responsivt design (mobil + desktop)

**Sikkert:**
- Alt kjører lokalt
- Ingen skytjenester
- EXIF-metadata fjernes fra bilder
- SQL injection beskyttelse

## Appendix: Ekstra Informasjon

### Detaljert Funksjonsliste

**Aktiviteter i systemet:**
1. Quiz (med bilder, tidsbegrensning, poeng)
2. QR Skattejakt (sjekkpunkter med hint)
3. Tripp-Trapp-Tresko (spiller mot hverandre)
4. Selfie-kjedet (møt andre, ta selfies)
5. Sosial Bingo (finn personer som matcher)
6. Bildeoppgaver (lagutfordringer med godkjenning)
7. Samle laget (scan alle lagmedlemmer, ta lagbilde)

**Admin-funksjoner:**
- Arrangementsinformasjon (logo, datoer, sted)
- Lagadministrasjon (opprett automatisk/manuelt)
- Deltakeradministrasjon (import, QR-koder)
- Soverom (tildel og print brannlister)
- Kurs (opprett, påmelding)
- Program (dag-for-dag oversikt)
- WiFi-info
- Tilbakemeldinger (anonym/identifisert)
- Statistikk og rapporter

### Systemkrav

**Minimum:**
- Windows 10 / macOS 10.14 / Linux
- Node.js v14 eller nyere
- 2 GB ledig diskplass
- Moderne nettleser (Chrome, Edge, Firefox, Safari)

**Anbefalt for arrangement:**
- Touchskjerm-PC eller laptop
- USB strekkodeskanner (2D QR-kompatibel)
- Webkamera for selfies
- Printer for QR-koder

**Fungerer også bare med:**
- Laptop + deltakernes mobiler
- Ingen ekstra hardware nødvendig!
