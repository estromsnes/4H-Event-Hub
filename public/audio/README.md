# Audio Files for Quiz

## Required Files

Place the following audio files in this directory:

### Quiz Background Music - Time-specific Tracks

Each time limit has its own audio file that loops during the question:

1. **5 Second Questions**
   - Filename: `quiz-5sec.mp3` or `quiz-5sec.ogg`
   - Duration: Should be 5 seconds long (will loop)

2. **10 Second Questions**
   - Filename: `quiz-10sec.mp3` or `quiz-10sec.ogg`
   - Duration: Should be 10 seconds long (will loop)

3. **20 Second Questions**
   - Filename: `quiz-20sec.mp3` or `quiz-20sec.ogg`
   - Duration: Should be 20 seconds long (will loop)

4. **30 Second Questions**
   - Filename: `quiz-30sec.mp3` or `quiz-30sec.ogg`
   - Duration: Should be 30 seconds long (will loop)

## Tips for Finding Audio

1. **Royalty-free music sites**:
   - [Pixabay](https://pixabay.com/music/)
   - [Free Music Archive](https://freemusicarchive.org/)
   - [YouTube Audio Library](https://www.youtube.com/audiolibrary)

2. **Kahoot-like sounds**:
   - Search for "quiz timer music" or "game show countdown music"
   - Look for tracks with a ticking/timer feel
   - Keep it short (10-30 seconds) as it will loop

3. **Audio settings**:
   - Volume is set to 30% in the code
   - Music starts when questions are displayed
   - Music stops when results are shown

## File Format

Both MP3 and OGG formats are supported for better browser compatibility.
